# Expenses Project

Учебный проект: работа с JSON и CSV в Python.

## Что делает

- Читает список расходов из `expenses.json`
- Cчитает сумму по каждой категории
- Выводит на экран
- Сохраняет сводку в `summary.json`
- Экспортирует список в `expenses.csv`

## Как запустить

```
python main.py
```

## Файлы

- `main.py` — основной скрипт
- `expenses.json` — входные данные
- `summary.json` — создаётся при запуске (в .gitignore)
- `expenses.csv` — создаётся при запуске (в .gitignore)
